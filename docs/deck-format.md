# Формат презентаций (.deck)

Все лекции и семинары собраны в том же формате, что и вводная лекция
[«Как работает сеть»](../lessons/w00-l00-networks/lecture.html): один HTML-файл без зависимостей,
слайды 1280×720, **простой** и **технический** режим (клавиша T), ответы в квизах (A), оглавление (G),
полный экран (F), режим «Основные», который пропускает дополнительные слайды, печать по слайду на страницу.
CSS и JavaScript взяты из образца без изменений (`tools/templates/`), добавлены только подсветка кода и пара блоков.

Исходник — текстовый файл `lecture.deck` / `seminar.deck` рядом с HTML. Сборка: `make decks`.

```text
title: Название занятия
kicker: Неделя 3 · Лекция
parts: Часть 1|Часть 2

@part 1
## Заголовок слайда | 4 | opt,cover      ← минуты; флаги: opt (дополнительный), cover, divider, break
- пункт списка с **жирным** и `кодом`
> «ага»-вывод (зелёная плашка)
! предупреждение (жёлтая плашка)
sub: подзаголовок        note: мелкая подпись        chips: тег | тег        big: 10 минут
flow: c:Бот ~ подпись -> g:FastAPI -> a:Redis       ← узлы: c g v a p r n — цвета
card: Заголовок карточки :: текст                   ← 2 карточки — две колонки, 3 — три, 4 — сетка 2×2
q: Вопрос квиза :: Ответ (скрыт до клика)
| Таблица | шапка |
| ячейка | ячейка |
```python Подпись окна        ← блок кода; «```python !small Подпись» — мелкий шрифт
print("hi")
```
:: tech                       ← дальше — содержимое технического режима этого слайда
card: Подробность :: ...
```

Одна лекция — 3 академических часа (135 минут) с перерывом; полный маршрут слайдов рассчитан на 120–135 минут,
«Основные» — около 100. Семинары короче по слайдам: большая часть времени — работа в командах.
