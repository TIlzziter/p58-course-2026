# Как устроены лабораторные

Формат повторяет учебный репозиторий «Перемена» (`veryBigSad/lms-example`): небольшой проект «как настоящий»,
в котором часть функций написана с ошибками, а часть не написана. В README лабораторной — таблица
«№ · файл/функция · что сделать · что проверить» с конкретными примерами.

```
lessons/wNN-lMM-<тема>/labs/labXX-<slug>/
├── README.md      условие: история, запуск, таблица задач, сдача
├── check.py       автопроверка: python check.py → таблица задач «OK / НЕТ»
├── pytest.ini
├── <код>.py       стартовый код (с ошибками и TODO)
└── tests/test_tN_*.py   тесты задачи N
```

* Лабораторные работают **без серверов**: FastAPI и WebSocket проверяются через `TestClient`,
  база — SQLite в памяти через SQLAlchemy (в проекте — PostgreSQL), Redis — `fakeredis`,
  конфиги Docker и GitHub Actions — разбором YAML.
* Зависимости одни на весь курс: `python -m pip install -r requirements.txt` (Python 3.12+).
* Запуск: `python check.py` (все задачи), `python check.py 3` (одна), `python check.py -v 3` (подробно).
  Можно и просто `pytest`.

## Где эталонные решения

Репозиторий публичный, решения лежат в нём же, но **отдельно от стартового кода** — в корневой папке `solutions/`:

* `solutions/labs/<lab>/` — файлы, которые надо положить поверх лабораторной, чтобы все тесты прошли
  (те же относительные пути).
* `solutions/contests/<contest>/` — решения задач контеста, тесты к ним (`pytest -q`) и заметки для проверки у экрана.

Ученики могут заглянуть в решения — это осознанное решение владельца курса. Правило «задача засчитывается,
только если можешь объяснить свой код» делает списывание бессмысленным.

## Проверка всего курса

`make check` (или `scripts/check_all.sh`) для каждой лабораторной:

1. копирует её во временную папку и проверяет, что тесты **каждой задачи падают** на стартовом коде;
2. накладывает эталон из `solutions/labs/` и проверяет, что **все тесты проходят**;

затем прогоняет тесты эталонов всех контестов и проверяет, что у каждого из 58 уроков есть README
и собранная, не устаревшая презентация.
