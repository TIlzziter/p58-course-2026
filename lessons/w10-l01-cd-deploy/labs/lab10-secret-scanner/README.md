# Лабораторная 10. Сканер секретов

Токен бота в публичном репозитории живёт **минуты**: боты, которые читают все новые коммиты GitHub, находят его быстрее
вас. Удаление коммита не помогает: токен уже скопирован, его нужно **отозвать** (`/revoke` у @BotFather).
Поэтому секреты лучше ловить до коммита. Пишем свой маленький сканер, похожий на `gitleaks` и `detect-secrets`, и ставим
его в git-хук `pre-commit`.

```bash
python check.py           # все задачи
python check.py -v 2      # подробности по задаче 2
```

Все «секреты» в тестах ненастоящие. Они собраны из кусков в `tests/fakes.py`, чтобы сам репозиторий курса не выглядел
как утечка.

## Задачи

| № | Что сделать |
|---|---|
| 1 | `shannon_entropy(s)`: энтропия Шеннона, **бит** на символ (`log2`), пустая строка → `0.0`. `looks_random(s, min_len, threshold)`: длина ≥ `min_len` **и** энтропия ≥ `threshold`. |
| 2 | `scan_line(text)`: правила из таблицы ниже, по порядку `RULES`. Если ни одно не сработало — `generic_assignment`. Строка с комментарием `secret-scan: ignore` пропускается. Для `url_password` значение — только пароль. |
| 3 | `mask(secret)`: `abcd…yz`, короче 10 символов → `***`. `scan_text(text, path)`: `Finding` с номером строки **с единицы**, превью маскировано. |
| 4 | `scan_tree(root)`: обойти все файлы (`rglob`), пропустить `SKIP_DIRS`, двоичные (байт `\0` в первом килобайте) и шаблоны из `.secretsignore` (`fnmatch` по пути и по имени файла, `#` — комментарий). Пути — относительные, через `/`, по алфавиту. |
| 5 | `parse_env(text)`: пустые строки и `#`, `export KEY=…`, пробелы вокруг `=`, кавычки `'…'`/`"…"` (внутри можно `#` и пробелы), комментарий после значения ` # …`, `=` внутри значения. Ошибка → `ValueError("строка N: …")`. `check_env(example, actual)` → `missing`, `extra`, `empty` (отсортированы). |
| 6 | `scan_diff(diff)`: только строки `+`, номера строк — в **новом** файле (из заголовка `@@ -a,b +c,d @@`); удалённые файлы (`+++ /dev/null`) пропускаем. |
| 7* | `redact(text, secrets)`: убрать из лога секреты, в том числе в URL-кодировке (`quote(s, safe="")`) и в base64 (без `=` на конце). Длинные варианты заменяем первыми, пустые секреты игнорируем. |

### Правила

| Правило | Что ищем |
|---|---|
| `telegram_bot_token` | 8–10 цифр, `:`, ровно 35 символов `A-Z a-z 0-9 _ -` (границы слова `\b`) |
| `github_token` | `ghp_`, `gho_`, `ghu_`, `ghs_`, `ghr_` + 36 букв и цифр |
| `aws_access_key` | `AKIA` + 16 заглавных букв и цифр |
| `private_key` | `-----BEGIN PRIVATE KEY-----`, а также с `RSA`, `EC`, `OPENSSH`, `DSA` перед `PRIVATE` |
| `url_password` | `схема://пользователь:пароль@` → пароль |
| `generic_assignment` | имя с `password`/`passwd`/`pwd` → любое значение от 6 символов; с `secret`/`token`/`api_key` → `looks_random(v, 8, 3.0)`. Не считаем заглушки: `changeme`, `your_…`, `<…>`, `${…}`, `$VAR`, `{{…}}`, `xxxx`/`****`, а также выражения без кавычек со скобками: `os.getenv("X")` |

## Проверка у экрана

1. Установите хук `precommit.py` в репозиторий команды (инструкция в начале файла).
2. Попробуйте закоммитить `.env` с токеном: коммит отклонён, токен в выводе замаскирован.
3. `python -c "from scanner import scan_tree; print(*scan_tree('.'), sep='\n')"` по всему репозиторию команды. Каждое
   найденное: настоящий секрет → отозвать и убрать; ложное срабатывание → `.secretsignore` или `secret-scan: ignore`.

даже если коммит удалили через `git push --force`?
