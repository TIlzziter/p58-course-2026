← / → — листать. T — простой / технический режим. A — открыть ответы. G — оглавление. F — полный экран. Esc — закрыть окно.

Переключение режима сохраняет текущий слайд. «Основные» пропускают дополнительные слайды. Полный маршрут — около 73 минут, основной — около 73 минут, включая перерыв.

Файл работает без интернета. Для живых демонстраций нужна сеть. Печать использует выбранный режим, раскрывает ответы и сохраняет один слайд на страницу.

docs/adr/003-redis-rooms.md
# 003. Состояние комнат — в Redis
Статус: принято · 2027-03-10
Контекст: две реплики API, игроки одной комнаты попадают на разные.
Решение: комната и ходы — в Redis, события — через pub/sub.
Последствия: + реплики без «липких» сессий; − Redis стал обязательным, нужен бэкап.
  • ADR — короткая запись «почему». Через полгода это самый ценный документ.
