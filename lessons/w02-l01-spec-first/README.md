> Рабочая версия 1 (29.10.2026): план перерабатывается по итогам встреч менторов, часть решений на согласовании и может измениться.

## Цели

- писать user story и проверяемые критерии приёмки
- описывать протокол API: пути, JSON, ошибки
- нарисовать архитектуру одного проекта: браузер → FastAPI → сервер учётных записей и игровая логика (бот и Mini App — после Нового года)

## Практика на уроке

Формат занятия: короткая презентационная часть + практические задания для самостоятельной работы на уроке.

1. по образцу со слайдов написать 3 user story для своей роли и по 2 критерия приёмки к каждой
2. описать один эндпоинт (например, ход в игре): путь, JSON запроса и ответа, 2 ошибки
3. в парах обменяться черновиками и найти непроверяемый критерий
