# Лабораторная 02. API по спеке

Агент сгенерировал каркас API крестиков-ноликов по [`SPEC.md`](SPEC.md) — и, как это бывает,
сделал «примерно то». Ваша роль — **ревьюер и доводчик**: найти все расхождения со спекой и исправить их.
Код игры разделён на две части: `app/game.py` — чистая логика без FastAPI, `app/main.py` — HTTP-слой,
`app/schemas.py` — модели запросов.

## Запуск

```bash
python -m pip install -r ../../../../requirements.txt   # один раз, из корня курса — fastapi, httpx, pytest
python check.py             # таблица задач
python check.py -v 4        # подробности по задаче 4
uvicorn app.main:app --reload   # по желанию: живой сервер и документация на http://127.0.0.1:8000/docs
```

Тесты запускают приложение через `TestClient` — сервер для проверки не нужен.

## Задачи

| № | Функция / файл | Что сделать | Что проверить |
|---|---|---|---|
| 1 | `health` в `main.py` | Ответ строго как в спеке. | `GET /health` → `{"status": "ok"}` |
| 2 | `create_room`, `get_room`, `schemas.py` | Код **201**, номера комнат с 1; 404 `room_not_found` для несуществующей комнаты; ограничения имени игрока. | имя `""`, `" аня"`, 21 символ → 422; 20 символов — можно |
| 3 | `join` | Второй игрок входит, партия начинается, ходит создатель. Ошибки `room_full`, `name_taken`, `room_not_found`. | после ошибки состояние комнаты не меняется |
| 4 | `move`, `MoveIn` | Все проверки хода **в порядке из спеки**, смена хода. | `cell` = 9 → 422; чужой ход → 409 `not_your_turn`; занято → 409 `cell_taken` |
| 5 | `game.py`, конец `move` | Победа по строкам, столбцам и диагоналям, ничья, `place` с ошибкой для занятой клетки; после конца партии ходить нельзя. | диагональ второго игрока; ничья `XOXXOOOXX` |
| 6 | `list_rooms` | Список комнат по возрастанию номера, фильтр `?status=`. | `?status=lost` → 422 |
| 7* | обработчик ошибок | Ошибки валидации FastAPI тоже в формате `{"detail": {"code": "validation_error", "message": ...}}`. | тело `{}` → `detail` — объект, а не список |

Подсказки:
* Задача 2: `@app.post(..., status_code=201)`; ограничения строки — `Field(min_length=..., max_length=..., pattern=...)`.
* Задача 4: если одна проверка не прошла, **ничего не меняйте** в комнате. Удобно: сначала все проверки, потом изменения.
* Задача 7*: `@app.exception_handler(RequestValidationError)` из `fastapi.exceptions`, ответ — `JSONResponse`.

## Ревью как часть задания

Перед тем как править код, пройдите по таблице эндпоинтов в `SPEC.md` и выпишите расхождения каркаса агента
в файл `REVIEW.md` (строка — одно замечание: где, что не так, как по спеке). Это ваш первый ревью-отчёт:
на семинаре сравним, кто нашёл больше расхождений **до** запуска тестов.

## Если задача «не идёт»

* Читайте первую строку ошибки в `python check.py -v N`: там ожидаемое и фактическое значение.
* Проверяйте руками в `/docs` — кнопка **Try it out**.
* Агенту можно поручить объяснить ошибку теста, но не «починить тест»: тесты — это спека.
