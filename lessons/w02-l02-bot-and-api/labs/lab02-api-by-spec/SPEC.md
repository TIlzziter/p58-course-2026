# Крестики-нолики — спецификация API v1.0

## Цель
Два игрока играют в крестики-нолики 3×3 через HTTP API. Клиент (Mini App) только показывает
состояние и отправляет ходы; **все правила проверяет сервер**.

## Модель
* `board` — строка из 9 символов, клетки по строкам слева направо: `0 1 2 / 3 4 5 / 6 7 8`.
  `.` — пусто, `X` — первый игрок (создатель комнаты), `O` — второй.
* `status`: `waiting` (ждём второго игрока) → `playing` → `finished`.
* `turn` — имя игрока, который ходит сейчас; `null`, если партия не идёт.
* `winner` — имя победителя; `null`, если победителя нет (в том числе при ничьей).
* Имя игрока: строка 1–20 символов, без пробелов в начале и в конце.

Ответ «комната» (`Room`):
```json
{"room_id": 1, "players": ["аня", "боря"], "board": "X...O....",
 "turn": "аня", "status": "playing", "winner": null}
```

## Эндпоинты
| Метод и путь | Тело | Успех | Ошибки |
|---|---|---|---|
| `GET /health` | — | 200 `{"status": "ok"}` | — |
| `POST /rooms` | `{"player": "аня"}` | **201** `Room`, статус `waiting` | 422 |
| `GET /rooms?status=waiting` | — | 200 список `Room` по возрастанию `room_id`; без `status` — все | 422 при другом значении `status` |
| `GET /rooms/{id}` | — | 200 `Room` | 404 `room_not_found` |
| `POST /rooms/{id}/join` | `{"player": "боря"}` | 200 `Room`, статус `playing`, ходит создатель | 404 `room_not_found`, 409 `room_full`, 409 `name_taken`, 422 |
| `POST /rooms/{id}/moves` | `{"player": "аня", "cell": 4}` | 200 `Room` после хода | см. ниже |

`room_id` — целые числа с 1, каждая новая комната получает следующий номер.

### Проверки хода (в этом порядке)
1. Тело неверное, `cell` вне 0..8 → **422** `validation_error`.
2. Нет комнаты → **404** `room_not_found`.
3. Игрок не в комнате → **403** `not_a_player`.
4. Партия не идёт (`waiting` или `finished`) → **409** `not_playing`.
5. Не его ход → **409** `not_your_turn`.
6. Клетка занята → **409** `cell_taken`.

После хода: три в ряд (строка, столбец или диагональ) → `finished`, `winner` — имя, `turn` — `null`.
Поле заполнено без трёх в ряд → `finished`, `winner` — `null`, `turn` — `null`.
Иначе ход переходит к сопернику.

## Ошибки
Все ошибки, включая 422, в одном формате:
```json
{"detail": {"code": "not_your_turn", "message": "Сейчас ходит аня"}}
```
`message` — для человека (на русском), `code` — для программы, из списка выше.
