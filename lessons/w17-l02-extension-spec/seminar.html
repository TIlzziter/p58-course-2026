Управление

← / → — листать. T — простой / технический режим. A — открыть ответы. G — оглавление. F — полный экран. Esc — закрыть окно.

Переключение режима сохраняет текущий слайд. «Основные» пропускают дополнительные слайды. Полный маршрут — около 40 минут, основной — около 40 минут, включая перерыв.

Файл работает без интернета. Для живых демонстраций нужна сеть. Печать использует выбранный режим, раскрывает ответы и сохраняет один слайд на страницу.

Что если модель недоступна

  • Каждый сценарий с моделью — с запасным путём: заготовленные фразы, «подсказка недоступна», выключатель.
  • Флаг LLM_ENABLED в настройках: выключили — игра работает как раньше.
  • Лимиты в спеке числами: запросов на игрока в минуту, токенов в день.

Первый прогон

  • Запускаем run_evals на заглушке (lambda text: "...") — проверяем сам набор.
  • Если есть доступ к модели у преподавателя — один общий прогон, ключ только у него.
  • Смотрим отчёт по тегам: что проваливается и почему — промпт, проверка или случай плохой?
Нельзя «чинить» evals, удаляя упавшие случаи. Удаляем только ошибочные — и пишем в PR почему.
