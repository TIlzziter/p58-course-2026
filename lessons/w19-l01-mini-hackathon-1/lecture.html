Управление

← / → — листать. T — простой / технический режим. A — открыть ответы. G — оглавление. F — полный экран. Esc — закрыть окно.

Переключение режима сохраняет текущий слайд. «Основные» пропускают дополнительные слайды. Полный маршрут — около 61 минут, основной — около 61 минут, включая перерыв.

Файл работает без интернета. Для живых демонстраций нужна сеть. Печать использует выбранный режим, раскрывает ответы и сохраняет один слайд на страницу.

Правила

  • Две команды по 4 человека; составы объявляет преподаватель — не по текущим командам игры.
  • Проект с нуля: можно взять свой шаблон с недели 18, нельзя брать код игры.
  • Агенты разрешены. Каждая правка агента — в журнале docs/agent-log.md.
  • Между сессиями можно работать, но журнал ведём и дома.

Работа с агентом

  • Одна задача — один промпт — один коммит. Промпт ссылается на раздел спеки.
  • Агенту — каркас, миграции, тесты, вёрстка по описанию. Людям — данные, API-контракт, демо.
  • Большая правка «на всё» за раз — почти всегда откат через полчаса.
Ключи и токены — в .env на сервере, не в промптах и не в журнале.
