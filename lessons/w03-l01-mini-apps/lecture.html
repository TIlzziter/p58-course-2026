Управление

← / → — листать. T — простой / технический режим. A — открыть ответы. G — оглавление. F — полный экран. Esc — закрыть окно.

Файл работает без интернета. Для живых демонстраций нужна сеть. Печать использует выбранный режим, раскрывает ответы и сохраняет один слайд на страницу.

Что такое Mini App

  • Обычная веб-страница (HTML, CSS, JS), которую Telegram открывает во встроенном браузере.
  • Открывается кнопкой бота, кнопкой меню или прямой ссылкой t.me/<бот>/<app>.
  • Страница подключает telegram-web-app.js и получает объект window.Telegram.WebApp.
  • Адрес страницы — только HTTPS.
Встроенный браузер
На Android — WebView на Chromium, на iOS — WKWebView (Safari), на компьютере — встроенный движок клиента. Проверяем на всех, на которых играют наши пользователи.
Чем отличается от сайта
Тема и цвета Telegram (themeParams), кнопки MainButton и BackButton, вибрация HapticFeedback, закрытие close(), развёртывание expand().

Как передать серверу
Клиент отправляет сырую строку initData (не разобранный объект!) в заголовке: Authorization: tma <initData>. Сервер проверяет подпись и только потом верит user.
Поле signature
В новых версиях есть ещё signature — подпись Ed25519 для проверки третьими лицами без токена. При проверке токеном бота она просто одно из полей.

Хеш и HMAC

  • Хеш (SHA-256): из любых данных — 32 байта «отпечатка». Изменился 1 бит — отпечаток совсем другой.
  • Но хеш может посчитать кто угодно: подделал данные — пересчитал хеш.
  • HMAC = хеш данных с секретным ключом. Без ключа правильный HMAC не посчитать.
Эксперимент
import hashlib, hmac
hashlib.sha256(b"id=42").hexdigest()[:16]     # '2a553fd53e66b69f' — посчитает любой
hmac.new(b"secret", b"id=42", hashlib.sha256).hexdigest()[:16]   # 'd04769d2311b20c5' — только зная ключ

Свойства
Устойчивость к подделке: зная пары (сообщение, HMAC), нельзя вычислить HMAC нового сообщения без ключа. Ключ знают только Telegram и наш сервер.
Почему не просто sha256(key + msg)
Для SHA-256 такая конструкция уязвима к атаке удлинения сообщения. HMAC специально построен (два вложенных хеша), чтобы этого не было.

Проверка в коде

api/auth.py
import hashlib, hmac
from urllib.parse import parse_qsl

def verify_init_data(raw: str, bot_token: str) -> dict | None:
    fields = dict(parse_qsl(raw, strict_parsing=True))
    received = fields.pop("hash", "")
    check = "\n".join(f"{k}={v}" for k, v in sorted(fields.items()))
    secret = hmac.new(b"WebAppData", bot_token.encode(), hashlib.sha256).digest()
    expected = hmac.new(secret, check.encode(), hashlib.sha256).hexdigest()
    return fields if hmac.compare_digest(received, expected) else None

    fields = dict(parse_qsl(raw, strict_parsing=True))

compare_digest
== завершает сравнение на первом расхождении — по времени ответа можно подбирать подпись. hmac.compare_digest работает за постоянное время.
parse_qsl
Декодирует %D0%90 в «А» и %26 в &. Ручное split("&") ломается на значениях, где есть = или &.

Свежесть и повторы

  • Подпись верна, но строку могли перехватить и прислать через неделю.
  • Проверяем: now - auth_date ≤ max_age (например, сутки) и auth_date не из будущего.
  • Для действий с последствиями (ставка, покупка) — короткий срок или своя сессия.
Сессия после входа
Частый приём: проверили initData один раз → выдали свой токен сессии (подписанный сервером) на час. Дальше запросы с ним.
Часы сервера
Проверка времени требует правильных часов. На VPS включаем синхронизацию времени (NTP), иначе «всё истекло» после перезагрузки.

from fastapi import Depends, Header, HTTPException

def current_user(authorization: str = Header(default="")) -> dict:
    if not authorization.startswith("tma "):
        raise HTTPException(401, detail={"code": "no_init_data", "message": "Нет initData"})

Рисуем поле «4 в ряд»

web/board.js
const CELL = 50, R = 20;
const COLORS = ["#0b1020", "#facc15", "#ef4444"];   // пусто, игрок 1, игрок 2

function draw(ctx, state) {
  ctx.fillStyle = "#1e3a8a";
  ctx.fillRect(0, 0, 7 * CELL, 6 * CELL);
  state.board.forEach((row, r) => row.forEach((v, c) => {
    ctx.beginPath();
    ctx.arc(c * CELL + CELL / 2, r * CELL + CELL / 2, R, 0, 2 * Math.PI);
    ctx.fillStyle = COLORS[v];
    ctx.fill();
  }));
  for (const [r, c] of state.win_cells) {            // подсветка победной четвёрки
    ctx.strokeStyle = "#fff"; ctx.lineWidth = 4;
    ctx.beginPath(); ctx.arc(c * CELL + CELL / 2, r * CELL + CELL / 2, R, 0, 2 * Math.PI); ctx.stroke();
  }
}

Чёткость на телефоне

  • У телефонов devicePixelRatio 2–3: canvas 350×300 растягивается и мылится.
  • Решение: внутренний размер × dpr, CSS-размер прежний, ctx.scale(dpr, dpr).
const dpr = window.devicePixelRatio || 1;
canvas.width = 350 * dpr; canvas.height = 300 * dpr;
canvas.style.width = "350px"; canvas.style.height = "300px";
ctx.scale(dpr, dpr);
