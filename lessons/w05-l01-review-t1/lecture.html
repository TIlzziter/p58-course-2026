FastAPI и Pydantic

api/routes.py
class Move(BaseModel):
    column: int = Field(ge=0, le=6)

@router.post("/rooms/{room_id}/moves")
def make_move(room_id: int, move: Move, user: dict = Depends(current_user)) -> dict:
    room = rooms.get(room_id)
    if room is None:
        raise HTTPException(404, detail={"code": "no_room", "message": "Нет комнаты"})
    try:
        room.game.drop(move.column, player=room.player_of(user["id"]))
    except GameError as e:
        raise HTTPException(409, detail={"code": e.code, "message": str(e)}) from None
    return room.state()

initData: почему серверу можно верить

  • Клиенту не верим: initDataUnsafe подделывается в DevTools за секунду.
  • Сервер сам проверяет подпись: поля без hash по алфавиту через \n → HMAC-SHA256.
  • Ключ: HMAC_SHA256(key="WebAppData", msg=bot_token). Токен знают только Telegram и наш сервер.
  • Сравнение — hmac.compare_digest; плюс свежесть auth_date.

Игра: логика отдельно от всего

  • Поле 6×7 — список списков: [[0] * 7 for _ in range(6)], а не [[0] * 7] * 6.
  • Фишка падает на нижнюю свободную клетку; полный столбец — ошибка.
  • Победа: 4 направления (0,1), (1,0), (1,1), (1,-1) от последней фишки в обе стороны.
  • Сервер — источник истины; клиент рисует то, что вернул сервер.

Docker, compose, nginx

  • Compose: сервисы видят друг друга по имени (db:5432), наружу — только nginx 80/443.
