Проверка хода

anticheat.py
def check(self, player, ts, x, y):
    if not (0 <= x < self.width and 0 <= y < self.height):
        return "out_of_bounds"
    prev = self.last.get(player)
    if prev:
        pts, px, py = prev
        if ts <= pts:
            return "stale"
        if hypot(x - px, y - py) / (ts - pts) > self.max_speed * 1.1:
            return "too_fast"
    self.last[player] = (ts, x, y)
  • Допуск 10 % — на неровную сеть. Отклонённый ход не применяем и пишем в лог с причиной.

Ведро токенов

ratelimit.py
def allow(self, cost=1):
    t = self.now()
    self.tokens = min(self.capacity, self.tokens + (t - self.last) * self.rate)
    self.last = t
    if self.tokens >= cost:
        self.tokens -= cost
        return True
    return False
  • Ведро на capacity токенов, пополняется со скоростью rate. Запрос забирает токен.
  • Разрешает короткий всплеск (до capacity), но в среднем — не больше rate в секунду.
  • Время — параметр now: в тестах подставляем свои часы и не ждём.

BEARER = re.compile(r"\bBearer\s+[^\s\"',]+", re.IGNORECASE)

    return BEARER.sub("Bearer ***", text)
