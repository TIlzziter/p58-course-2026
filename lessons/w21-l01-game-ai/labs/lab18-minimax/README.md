# Лабораторная 18. Минимакс, альфа-бета и Монте-Карло

ИИ-соперник для двух игр: крестики-нолики (дерево маленькое, можно перебрать целиком) и «Четыре в ряд»
(дерево огромное — нужны отсечения, эвристика и ограничение глубины). В конце — Монте-Карло: соперник,
которому не нужна оценочная функция.

```bash
python check.py           # все задачи
python check.py -v 3      # подробности по задаче 3
```

Интерфейс игры (`games.py`): `initial()`, `to_move(s)`, `moves(s)`, `play(s, m)`, `winner(s)` — `1`/`-1`
победитель, `0` ничья, `None` игра идёт. Состояние — кортеж `(board, to_move)`, его можно класть в словарь.
`parse("XX./OO./...")` превращает картинку в состояние (у «Четырёх в ряд» строки сверху вниз).

Все значения — **с точки зрения первого игрока**: он максимизирует, второй минимизирует.

## Задачи

| № | Файл | Что сделать |

## Как это подключается в проекте

* ИИ-соперник — это функция `состояние → ход` на сервере: тот же интерфейс, что у игровой логики недели 5.
  Сервер вызывает её, когда в комнате бот, и шлёт ход через WebSocket как обычный ход игрока.
* Глубина и число итераций — это «уровень сложности». Ограничиваем по времени (например, 200 мс на ход),
  иначе один бот съест процессор сервера: тяжёлый поиск выносим в отдельный процесс или воркер.
* Ход бота должен проходить ту же проверку правил, что и ход человека.
* Агент быстро напишет минимакс, но ошибается в знаках (кто максимизирует) и в отсечениях. Проверка — тесты
  на позициях с известным ответом и турнир «решение агента против своего» (семинар 21).
