Управление

← / → — листать. T — простой / технический режим. A — открыть ответы. G — оглавление. F — полный экран. Esc — закрыть окно.

Переключение режима сохраняет текущий слайд. «Основные» пропускают дополнительные слайды. Полный маршрут — около 94 минут, основной — около 94 минут, включая перерыв.

Файл работает без интернета. Для живых демонстраций нужна сеть. Печать использует выбранный режим, раскрывает ответы и сохраняет один слайд на страницу.

requestAnimationFrame

let last = performance.now();
function frame(now) {               // браузер передаёт время кадра, мс
  const dt = Math.min(now - last, 100); last = now;   // вкладка спала — не прыгаем
  update(dt);                        // анимации, интерполяция
  draw();                            // только рисование, без сети
  requestAnimationFrame(frame);      // попросить следующий кадр
}
requestAnimationFrame(frame);

Интерполяция снимков

render.js
const DELAY = 100;                                  // на тик позади
function draw(now) {
  const t = clock.serverNow(now) - DELAY;           // время отрисовки
  const [prev, next, a] = buffer.sample(t);         // два снимка вокруг t
  for (const id in next.snakes)
    drawSnake(lerpPoints(prev.snakes[id], next.snakes[id], a));
}
  • Буфер хранит последние снимки по времени сервера, вставка по порядку: пакеты могут поменяться местами.
  • a = (t − t₀) / (t₁ − t₀) — доля пути между снимками.
  • Цена: всё на экране отстаёт на DELAY. 100 мс почти незаметны, 300 — уже да.

Часы сервера

  • t в буфере — время сервера, performance.now() — время клиента. Нужна разница.
  • Пинг: клиент шлёт sent, сервер отвечает своим server, ответ приходит в received.
  • Оценка: offset = server − (sent + received) / 2, если путь туда и обратно одинаковый.
  • Берём замер с наименьшим RTT из последних нескольких: у него меньше неопределённость.

Телефон: экран и пальцы

  • Высота: берём из tg.viewportStableHeight или CSS-переменной --tg-viewport-stable-height, а не 100vh.
  • Поле квадратное и целиком на экране: размер клетки = min(ширина, высота) / N, целые пиксели.
  • Свайпы: pointerdown → pointerup, направление по большей разнице dx/dy, порог 20–30 px.
  • touch-action: none на поле, иначе свайп прокрутит страницу или свернёт Mini App.
  • Кнопки-стрелки — для тех, кому свайп неудобен. Размер касания не меньше ≈ 44 px.
