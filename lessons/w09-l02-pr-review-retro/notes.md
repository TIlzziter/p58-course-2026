### Модуль на каникулы: QuestHub (по желанию)

QuestHub — проект прошлых лет: сервер на FastAPI и Telegram-бот на aiogram для квестов. Это настоящий «чужой» код
со своей историей. Такой код вы будете встречать на PROD, на стажировке и в любом проекте, который живёт дольше полугода.

Задание (2–4 часа, засчитывается бонусом в рейтинг по решению преподавателя):

1. Склонировать репозиторий QuestHub (ссылку даёт преподаватель) и запустить его локально по README.
   Секреты в `.env` — свои, ключи из чужих логов и файлов не используем.
2. С агентом составить карту кода: где эндпоинты, где работа с БД, где обработчики бота. Результат — `MAP.md`
   на одну страницу.
3. Найти три проблемы: нет тестов, секрет в коде, необработанная ошибка, устаревшая зависимость и т. п.
   Для каждой проблемы описать, как её воспроизвести.
4. Исправить одну из них отдельным PR: ruff и тесты проходят, описание по шаблону с семинара.
