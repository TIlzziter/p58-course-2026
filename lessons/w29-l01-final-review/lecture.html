Управление

← / → — листать. T — простой / технический режим. A — открыть ответы. G — оглавление. F — полный экран. Esc — закрыть окно.

Переключение режима сохраняет текущий слайд. «Основные» пропускают дополнительные слайды. Полный маршрут — около 92 минут, основной — около 92 минут, включая перерыв.

Файл работает без интернета. Для живых демонстраций нужна сеть. Печать использует выбранный режим, раскрывает ответы и сохраняет один слайд на страницу.

ИИ-соперник: минимакс

bot.py
def minimax(g, depth, alpha=-INF, beta=INF, me=True):
    if depth == 0 or g.over():
        return g.score()
    best = -INF if me else INF
    for m in g.ordered_moves():           # хорошие ходы первыми — больше отсечений
        v = minimax(g.play(m), depth - 1, alpha, beta, not me)
        if me:
            best, alpha = max(best, v), max(alpha, v)
        else:
            best, beta = min(best, v), min(beta, v)
        if alpha >= beta:
            break                         # альфа-бета: дальше смотреть незачем
    return best
  • Альфа-бета даёт тот же ответ, что минимакс; в лучшем порядке ходов — около b^(d/2) позиций вместо b^d.
