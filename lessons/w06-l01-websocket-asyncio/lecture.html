Управление

← / → — листать. T — простой / технический режим. A — открыть ответы. G — оглавление. F — полный экран. Esc — закрыть окно.

Переключение режима сохраняет текущий слайд. «Основные» пропускают дополнительные слайды. Полный маршрут — около 98 минут, основной — около 93 минут, включая перерыв.

Файл работает без интернета. Для живых демонстраций нужна сеть. Печать использует выбранный режим, раскрывает ответы и сохраняет один слайд на страницу.

async def и await

asyncio_demo.py
import asyncio

async def player(name: str, delay: float) -> str:
    print(f"{name} думает…")
    await asyncio.sleep(delay)            # пока ждём — работают другие
    print(f"{name} походил")
    return name

async def main():
    first = await player("Аня", 1)                                       # ~1 c
    both = await asyncio.gather(player("Боря", 2), player("Вика", 2))   # ~2 c, а не 4
    print(first, both)

asyncio.run(main())

Корутина
player("Аня", 1) ничего не выполняет, а создаёт объект корутины. Выполнится она, когда её await-нут или превратят в задачу.
gather
Запускает корутины конкурентно и ждёт все; результаты в порядке аргументов. Время — по самой долгой, а не сумма.

Главная ошибка: блокировка цикла

  • time.sleep(1) внутри async def останавливает весь сервер на секунду: все игроки ждут.
  • То же с requests.get(...), тяжёлым циклом на секунду, синхронным драйвером базы.
  • Ждём — через await с асинхронной библиотекой: asyncio.sleep, httpx.AsyncClient, asyncpg.
  • Синхронное и тяжёлое — в отдельный поток: await asyncio.to_thread(func, arg).
Признак блокировки: один игрок делает тяжёлый ход — у всех остальных «зависает» игра.

WebSocket в FastAPI

api/ws.py
from fastapi import FastAPI, WebSocket, WebSocketDisconnect

app = FastAPI()

@app.websocket("/ws/echo")
async def echo(websocket: WebSocket):
    await websocket.accept()
    try:
        while True:
            msg = await websocket.receive_json()
            await websocket.send_json({"type": "echo", "data": msg})
    except WebSocketDisconnect:
        print("клиент ушёл")

Одна корутина на соединение
На каждого клиента FastAPI запускает свой вызов echo. Пока он ждёт receive_json, цикл обслуживает остальных.
Отключение
Когда клиент закрыл вкладку, receive_* бросает WebSocketDisconnect. Уборку (выход из комнаты) делаем в except или finally.

Комната и рассылка

api/rooms.py
class Room:
    def __init__(self, room_id: str):
        self.id, self.players, self.game = room_id, {}, Game()

    def handle(self, name: str, msg: dict) -> list[tuple[str, dict]]:
        if self.players[name] != self.game.turn:
            return [(name, {"type": "error", "code": "not_your_turn"})]
        self.game.play(msg["col"])
        state = {"type": "state", "state": self.game.to_json()}
        return [(player, state) for player in self.players]

class Room:
    def __init__(self, room_id: str):
        self.id, self.players, self.game = room_id, {}, Game()

    def handle(self, name: str, msg: dict) -> list[tuple[str, dict]]:
        if self.players[name] != self.game.turn:

        state = {"type": "state", "state": self.game.to_json()}
        return [(player, state) for player in self.players]
Исходящие вместо отправки
Комната не трогает сокеты, а возвращает список «кому что». Её легко тестировать без сети, а отправку делает тонкий слой.
Источник истины
Ход проверяет сервер. Клиент только присылает намерение и рисует состояние, которое пришло.

Переподключение

client.js
const hello = JSON.stringify({ type: "hello", room });
let delay = 500;
function connect() {
  const ws = new WebSocket(url);
  ws.onopen = () => { delay = 500; ws.send(hello); };
  ws.onclose = () => {
    setTimeout(connect, delay);
    delay = Math.min(delay * 2, 10000);
  };
}
  • После hello — полное состояние комнаты; задержка растёт вдвое до 10 с, чтобы не завалить сервер.
