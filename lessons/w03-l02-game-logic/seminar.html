Управление

← / → — листать. T — простой / технический режим. A — открыть ответы. G — оглавление. F — полный экран. Esc — закрыть окно.

Переключение режима сохраняет текущий слайд. «Основные» пропускают дополнительные слайды. Полный маршрут — около 94 минут, основной — около 89 минут, включая перерыв.

Файл работает без интернета. Для живых демонстраций нужна сеть. Печать использует выбранный режим, раскрывает ответы и сохраняет один слайд на страницу.

Каждая функция — чистая или почти чистая: вход → выход, без HTTP и глобальных переменных.
Четыре направления
(0,1) вправо, (1,0) вниз, (1,1) вниз-вправо, (1,-1) вниз-влево. Остальные четыре — те же линии с другого конца.

Хорошая задача для агента — «напиши winning_line по этим тестам». Плохая — «сделай игру». Тесты пишет человек.

Тонкий HTTP-слой

api/routes/moves.py
@app.post("/rooms/{room_id}/moves")
def move(room_id: int, body: MoveIn, user: dict = Depends(current_user)) -> dict:
    room = rooms.get(room_id)
    if room is None:
        raise error(404, "room_not_found", "Нет комнаты")
    if user["id"] != room.player_ids[room.game.turn - 1]:
        raise error(409, "not_your_turn", "Сейчас ход соперника")
    try:
        room.game.play(body.column)
    except MoveError as e:
        raise error(409, e.code, "Ход невозможен") from None
    return room.game.to_json()

Перевод ошибок
Логика бросает MoveError("column_full"), HTTP-слой превращает это в 409 с тем же code. Список кодов — один, в спеке.
Кто игрок
user приходит из current_user — проверенной initData. Никаких player_id из тела запроса.
