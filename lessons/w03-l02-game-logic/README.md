## Практика на уроке

Формат занятия: короткая презентационная часть + практические задания для самостоятельной работы на уроке.

1. руками: поле 7×6 и ход в столбец; тест на полный столбец
2. руками: проверка победы по горизонтали, вертикали и диагоналям — по тесту на каждый случай

4. фронтенд: клик по столбцу → запрос → перерисовка поля
