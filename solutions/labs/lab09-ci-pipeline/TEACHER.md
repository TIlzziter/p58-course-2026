# Lab09 — заметки преподавателю

* Задача 1 — главный «ага»: `yaml.safe_load("on: push")` → `{True: "push"}`. Покажите это в REPL до начала работы.
  Там же покажите `3.10` → `3.1`. Это проблема YAML 1.1, GitHub читает так же; поэтому версии пишем в кавычках.
* Задача 2: решение через Кана за O(n²) достаточно (jobs мало). Если кто-то пишет DFS, проверьте, что порядок
  «по файлу» при равной готовности сохраняется (`test_ties_by_file_order`).
* Задача 3: тонкость — include дописывает только **новые** ключи; исходные значения матрицы не перезаписывает.
  Матрица только из include — частый приём для «разнородных» запусков.
* Задача 4: порядок замечаний фиксирован, чтобы тесты были однозначны. `secret_in_run` проверяем поиском
  подстроки `${{ secrets.` (вариант без пробела тоже ловим).
* Задача 5: в эталоне `services: redis` и `REDIS_URL` — заготовка под проект команды (лаба 08).
  Тесты не требуют services.
* Обсуждение: закрепление по SHA (`@11bd719…`) надёжнее тега `@v4`, теги можно передвинуть. Dependabot умеет
  обновлять SHA. Линтер считает тег допустимым: компромисс для школьного проекта.
* Ruff и pytest в sample проходят «из коробки» — ломать надо только workflow.
