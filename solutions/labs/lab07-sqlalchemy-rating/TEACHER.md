# Лабораторная 07 — заметки к эталону

Эталон накладывается поверх папки лабораторной (`models.py`, `elo.py`, `repo.py`, `app.py`, миграция).

Ошибки в миграции агента (задача 7), которые должны найти ученики:
1. нет `UniqueConstraint("tg_id")`;
2. нет индекса `ix_matches_played_at`;
3. `result` — `String(16)` вместо `String(8)` (расхождение типа с моделью);
4. внешние ключи без `ondelete="CASCADE"`;
5. нет CHECK-ограничений (autogenerate их не сравнивает — находим только глазами, это хороший вопрос на ревью);
6. `downgrade` удаляет только `players` и не трогает `matches`.

Частые ошибки: `expected` с перевёрнутым знаком; два независимых округления (сумма рейтингов «плывёт»);
`commit()` внутри `record_match`; таблица лидеров считает партии только за первую сторону.
