# Lab10 — заметки преподавателю

* Энтропия: `hunter2hunter2` ≈ 2.81 бит на символ, hex-ключ из 32 символов — около 3.5–4. Отсюда два уровня у
  `generic_assignment`: пароли ловим по имени переменной, токены — по случайности значения.
* Самая частая ошибка в задаче 2 — двойное замечание (`telegram_bot_token` + `generic_assignment` на одной строке).
  Правило «generic только если остальные молчат» — компромисс ради меньшего шума.
* Задача 4: `.git/config` содержит URL с токеном, если клонировали по HTTPS с токеном, — хороший повод обсудить.
* Задача 6: в `git diff -U0` заголовок бывает `@@ -3 +3 @@` (без длины) — регулярка должна это принимать.
* `precommit.py` реально работает после задачи 6; хук обходится `git commit --no-verify`. Поэтому в CI
  дополнительно нужен сканер (на семинаре — `gitleaks` в workflow или наш `scan_tree`).
* Обсудить: GitHub Push Protection блокирует известные форматы токенов при пуше в публичный репозиторий, но
  знает не все форматы и легко обходится. Рассчитывать на это нельзя.
