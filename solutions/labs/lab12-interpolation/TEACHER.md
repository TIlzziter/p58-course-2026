# Lab12 — заметки преподавателю

* Главная идея: клиент рисует прошлое. Начните с демо `demo/index.html`. Покажите его без интерполяции и с джиттером
  80 мс, затем включите интерполяцию.
* Задача 2: частая ошибка — `append` вместо вставки по времени. При джиттере пакеты меняются местами, и змейка
  «дёргается назад». Тест `test_out_of_order_inserted_sorted`.
* Задача 3: телепорт (проход сквозь стену в режиме «тор», респаун) без порога выглядит как пролёт через всё поле.
* Задача 4: это алгоритм Кристиана (вариант NTP): чем меньше RTT, тем меньше неопределённость. Предположение — путь
  туда и обратно симметричен.
* Задача 5: в змейке предсказание для своей головы спорно (сервер может развернуть иначе), но для «танчиков» и
  движения по клеткам оно убирает ощущение задержки. Обсудить, когда предсказание вредит: столкновения с другими.
* Задача 7*: ответ на «почему не max» — один выброс навсегда увеличил бы задержку; поэтому перцентиль по окну.
