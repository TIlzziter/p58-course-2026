# Контест 7 — решения и заметки для преподавателя

* `tasks.py` — A1–D3, `query.py` — E4 а–в, `merge.py` — E5*, `test_c07.py` — тесты (`pytest -q` в этой папке).
* У экрана:
  * E1: засчитывать фильтр по полю JSON (`jq 'select(.room == "R1" and .level == "ERROR")'` или Python),
    а не `grep R1` — он ловит и `R10`.
  * E2: спросить, зачем `for: 2m`, и что будет, если контейнер перезапускается каждые 30 секунд.
  * E3: в постмортеме не должно быть виноватых людей — только причины и действия. Проверить, что ученик
    сам открыл логи и сверил вывод агента, а не переписал его.
* Частые ошибки:
  * A1 — считают `<testcase>` с `<skipped/>` прошедшим; `time` без округления (`1.5350000000000001`).
  * A2 — тест, которого нет в части запусков, считают упавшим там.
  * A3 — одиночная строка выводится как `5-5`; `skip` забывают.
  * A4* — жадный алгоритм (сначала тест, убивающий больше всех) не всегда даёт минимум: в тесте `greedy_trap`
    жадный берёт `tC` (4 мутанта) и потом ещё два теста, а хватает `tA, tB`. Перебор по размеру —
    `itertools.combinations` от 0 до n (тестов ≤ 15).
  * B1 — `split()` по пробелам ломается на user agent с пробелами; нужен regex. `bytes = "-"`.
  * B3 — `sorted` по `ts` устойчив — это и есть «в исходном порядке»; ручная сортировка его теряет.
  * C1 — сброс счётчика: прирост на шаге с перезапуском — новое значение, а не разность (отрицательная).
  * C2 — самый долгий простой в конце списка не учитывают (нет `True` после него).
  * C3 — `100000 * (1 - 0.9995)` = `49.99999…`; `int()` даёт 49. Нужно `round` (в тестах есть такой случай).
  * C4* — окно в начале: делят на `long`, а не на число имеющихся минут; «больше», а не «не меньше».
  * D1 — касающиеся интервалы `(10, 35)` и `(30, 35)` не сливают; общий простой считают до слияния.
  * D2 — окно отсчитывают от последнего **пришедшего** алерта, а не от последнего оставленного.
  * D3 — `T+61:00` вместо `T+1:01:00`.
  * E4а — `ms>>1` разбирают как `ms > ">1"`; `"-3"` не превращают в число.
  * E4б — сравнение строки с числом падает `TypeError` вместо «ложно».
  * E5* — склеивают все файлы и сортируют по `ts`: строки трейсбека без `ts` теряются или уезжают.
    Решение — `heapq` по записям `(ts, файл, номер, строки)`.
