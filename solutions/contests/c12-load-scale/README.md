# Контест 12 — решения и заметки для преподавателя

* `tasks.py` — A1–D3, `autoscale.py` — E4 а–в, `breaker.py` — E5*, `test_c12.py` — тесты (`pytest -q` в этой папке, < 1 с).
* У экрана:
  * E1: у каждой задачи — проверяемый критерий («→ 429 после трёх подсказок»), а не «сделать подсказки».
  * E2: засчитываем, только если ученик сам объясняет, что было не так в PR, — а не «агент переделал».
  * E3: выключение флага — без перезапуска кода (переменная окружения + рестарт контейнера допустим).
* Частые ошибки:
  * A1 — пропускают пустые секунды (`[2, 1, 2]` вместо `[2, 1, 0, 2]`).
  * A2 — граница «терпят» включает T: задержка ровно T — «доволен».
  * A3 — `(1 − 0.999) · 100000` во float даёт 99.99999…; без поправки получается 99. В решении `+ 1e-9`.
  * A4* — интерполяция внутри корзины — тоже допустимый ответ устно, но в задаче — верхняя граница.
  * B1 — ρ = 0.8 → W = 50 мс, ρ = 0.95 → 200 мс: вчетверо. Главная мысль — не грузить сервер «под 100 %».
  * B2 — считают ожидание от момента освобождения предыдущего запроса, а не от прихода текущего.
  * B3 — копят токены выше `capacity` или начинают с пустого ведра.
  * C1 — с 4 на 8 переезжает половина: `k % 8` даёт `k % 4` или `k % 4 + 4`.
  * C2 — из 2000 ключей переезжает 494 (≈ ¼), и все — на `api4`. Без виртуальных узлов распределение очень неровное.
  * C3 — `dict` без `move_to_end` даёт FIFO, а не LRU (cap = 2: попаданий 1 и там, и там — смотрим cap = 3).
  * C4* — забывают удалить ключ из `inflight` при исключении: потом все `get` вечно получают старую ошибку.
  * D1 — регулярка для чисел заменяет цифры внутри имён (`users2`) — нужна граница слова `\b`.
  * D2 — 200 · 2 · 0.015 = 6 соединений в среднем, с запасом 30 % — 9; 100 соединений Postgres → 10 реплик.
  * D3 — индекс `(room, player_id)` не помогает запросу только по `player_id`: не левый префикс.
  * E4а — `ceil` от float: `current · ratio` вроде `4.000000001` даёт 5 вместо 4; в решении `ceil(x − 1e-9)`. Забывают допуск `tolerance` — реплики «дёргаются» при 65 % вместо 60 %.
  * E4в — 200 запросов теряются на второй минуте: автомасштаб всегда реагирует с задержкой, нужен запас.
  * E5* — в полуоткрытом состоянии пропускают все запросы, а не один пробный.
