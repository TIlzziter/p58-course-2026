# Контест 13 — решения и заметки для преподавателя

* `tasks.py` — A1–D3, `jobs.py` — E4 а–в, `lease.py` — E5*, `test_c13.py` — тесты (`pytest -q` в этой папке, < 1 с).
* У экрана:
  * E1: доля участников («4 из 5»), а не «многим не понравилось»; повторный тест — хотя бы с одним новым человеком.
  * E2: восстанавливал не автор runbook; время и сверка строк записаны в отчёт учений.
  * E3: бэкап лежит не только на сервере с базой; файл вчерашний, а не сделанный перед уроком.
* Частые ошибки:
  * A1 — `re.findall` без `fullmatch` принимает `"30m1h"` и мусор между частями.
  * A2 — `datetime.utcnow()` и «наивные» даты; прибавляют 3 часа руками вместо `zoneinfo`. 28.03.2027 —
    переход на летнее время в ЕС: в Берлине сутки длятся 23 часа (23:00Z → 22:00Z).
  * A3 — не объединяют пересекающиеся простои — считают 100–300 дважды.
  * A4* — `weekday()` в Python: понедельник = 0, в cron воскресенье = 0; нужно `isoweekday() % 7`.
  * B1 — без джиттера тысяча клиентов повторяет запрос в одну и ту же секунду и снова роняет сервер.
  * B2 — ловят все исключения и повторяют ошибку в коде (`KeyError`) — повторять имеет смысл только сбои сети.
  * B3 — запоминают ответ до успешного вызова: после падения клиент навсегда получает «пустой» ответ.
  * C1 — две реплики по 0.99 дают 0.9999, но цепочка всё равно не лучше самого слабого последовательного звена.
  * C2 — 99.9 % за 30 дней — 43 минуты в месяц; «три девятки» — это меньше часа на все деплои.
  * C3 — MTBF считают от начала до начала инцидентов; здесь — по времени работы, как в формуле.
  * C4* — без гистерезиса балансировщик «мигает» репликой при каждом единичном таймауте.
  * D1 — при `recv` забывают `+ 1`.
  * D2 — пропущенный ключ — это 0, а не «несравнимо».
  * D3 — сравнивают только время: при равенстве результат зависит от порядка реплик.
  * E4б — задача `c` после 4 неудач уходит в dead letter в момент 9 (2 + 1 + 2 + 4).
  * E4в — повторная доставка — норма для очередей; защищает только проверка `id` события.
  * E5* — без fencing-токена «зомби» A, проснувшийся после паузы GC, затирает запись нового лидера B.
