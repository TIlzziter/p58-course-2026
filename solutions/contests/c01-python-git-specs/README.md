# Контест 1 — решения и заметки для преподавателя

* `tasks.py` — A1–C3, `app.py` — E1 и E4 (части а–в), `test_c01.py` — тесты (`pytest -q` в этой папке).
* E5* — образцом служат тесты `test_e4_*` в `test_c01.py`.
* D1–D3 и E2–E3 проверяются у экрана:
  * D1: коммиты по одному на задачу, сообщения по правилу; `git log --oneline` читается как список задач.
  * D2: в PR есть все разделы шаблона и `Closes #N`; issue закрылась автоматически.
  * D3*: в истории виден merge-коммит с двумя родителями, в `AGENTS.md` нет маркеров конфликта, оба правила на месте.
  * E2: токен берётся из `os.environ["BOT_TOKEN"]`, кнопка — `InlineKeyboardButton(text="Играть", web_app=WebAppInfo(url=...))`
    (или `KeyboardButton` с `web_app`); адрес — HTTPS. Образец — `lessons/w02-l02-bot-and-api/seminar.deck`, слайд «Бот за 20 строк».
  * E3: засчитываем, если найдено ≥ 2 содержательных замечания. Типичные: нет `status_code=201`, нет ограничения
    длины названия, `id` через `len(ROOMS)` даёт повторы после удаления, лишний глобальный счётчик без блокировки.
* Частые ошибки: A3 — смотрят только на последний вердикт; C3 — `isinstance(True, int)` истинно;
  B4 — перебирают все разбиения дважды (это не ошибка, но вдвое медленнее).
