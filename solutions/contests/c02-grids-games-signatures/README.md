# Контест 2 — решения и заметки для преподавателя

* `tasks.py` — A1–D3, `minesweeper.py` — E4 (части а–в), `app.py` — E1 и E5*, `test_c02.py` — тесты
  (`pytest -q` в этой папке; токен для E1 тесты подставляют сами через `monkeypatch`).
* `deploy/` — образец для D4*, E2 и E3: `Dockerfile`, `.dockerignore`, `compose.yml`, `nginx.conf`,
  `static/index.html` (canvas 6×7 с подсветкой столбца и учётом `devicePixelRatio`).
  Отчёт `report(...)` из лабы 5 на этих файлах: «Замечаний нет ✅».
* E5* — образцом служит `test_e5` в `test_c02.py`.
* У экрана проверяются:
  * D4*: `docker images` — образ на `python:3.12-slim` меньше 250 МБ; `docker run --rm <образ> id` не даёт `uid=0`;
    `docker history` показывает слой с `pip install` до `COPY` кода; в образе нет `.env` (`docker run --rm <образ> ls -a`).
  * E2: на телефоне или в DevTools с DPR 2 круги не размыты (`canvas.width = css_width * dpr` + `setTransform`);
    клик по последнему пикселю справа попадает в столбец 6, а не в 7.
  * E3: `docker compose ps` — у `app` нет опубликованных портов; `curl -X POST localhost:8080/api/check -H 'content-type: application/json' -d '{"init_data":"x"}'`
    отвечает `{"ok":false,"user_id":null}`. Частая ошибка — `proxy_pass http://app:8000;` без слэша: тогда приложению
    приходит `/api/check` и 404.
* Частые ошибки:
  * A2 — `[[0] * cols] * rows` (все строки — один список) или изменение исходного поля.
  * B1 — проверка только от левого верхнего края или выход за границы через отрицательные индексы (Python не падает
    на `board[-1]`, а молча берёт последнюю строку!).
  * B3 — `round` вместо `int`/`//`; клик ровно на правой границе (`x == css_w`) должен давать `None`.
  * B4* — проверяют победу соперника раньше своей; забывают, что полный столбец ходом не является.
  * C2 — сравнение `==` (засчитываем, но спрашиваем про timing attack); забывают `.lower()` для подписи заглавными.
  * D2 — `localhost:5000/api` разбирают как образ `localhost` с тегом `5000/api`.
  * D3 — отрезают `#` внутри кавычек (`HASH="a#b"`).
  * E1 — используют `parse_qs` и получают списки; падают с 500 на мусорной строке; проверяют подпись, но не свежесть.
  * E4б — рекурсивный flood fill на поле 30×30 упирается в лимит рекурсии; открывают клетки под флагом.
  * E5* — отдают `mines` в ответе «для отладки».
