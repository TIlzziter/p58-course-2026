# Контест 6 — решения и заметки для преподавателя

* `tasks.py` — A1–D3, `replay.py` — E4 а–в, `sweep.py` — E5*, `test_c06.py` — тесты (`pytest -q` в этой папке).
* У экрана:
  * E1: попросить закрыть Mini App у одного игрока посреди партии и открыть снова — должен вернуться в ту же комнату
    (состояние на сервере, не на клиенте).
  * E2: в DevTools *Network → Slow 3G*; спросить, на сколько клиент отстаёт от сервера и почему так задумано.
  * E3: засчитывать вывод с цифрами (МБ загрузки, секунды до первого кадра), а не «Pyodide медленный».
* Частые ошибки:
  * A1 — цикл `i` вверх вместо вниз; A2 — `bisect_left` (на границе 70 даёт `common`).
  * A3 — забывают, что ответ — числа после `seed`, а не включая его.
  * A4* — наивное перемешивание даёт `nⁿ` равновероятных вариантов, а `nⁿ` не делится на `n!` при `n ≥ 3` —
    равномерно быть не может. Хороший устный вопрос.
  * B1 — `KeyError` на неизвестном событии; B3 — смотрят только на прямые переходы, а не на достижимость.
  * C1 — `<=` вместо `<` (касание); C2 — `math.dist` с `float` и сравнение `==`.
  * C3 — проверка только концов отрезка; пролёт насквозь без концов внутри — тест `(0, 0) → (10, 4)`.
  * C4* — кладут прямоугольник в одну клетку по левому верхнему углу и теряют пары.
  * D1 — `(a + (b − a)·t) % 360` идёт по длинной дуге; D2 — `while acc >= step` без ограничения.
  * E4в — линейный перебор; тест считает вызовы `check`.
  * E5* — проверяют пересечение только в конце тика (`t = 1`) — тест с тонкой стеной.
