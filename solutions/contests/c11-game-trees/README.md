# Контест 11 — решения и заметки для преподавателя

* `tasks.py` — A1–D3, `pig.py` — E4 а–в, `solver.py` — E5*, `test_c11.py` — тесты (`pytest -q` в этой папке, ≈ 1 с).
* У экрана:
  * E1: позиции с известным ответом должны быть именно тестами в репозитории, а не «я проверил руками».
  * E2: оптимизация засчитывается по замеру p95, а не по словам агента. «Ничего не дала» — тоже результат.
  * E3: показать два терминала с разными репликами (`docker compose logs api`), ход в одном виден в другом.
* Частые ошибки:
  * A1 — считают различные **значения** подмножеств, а не позиции (`[2, 2, 2]` → 3, а не 1). Перебор — 2ⁿ.
  * A2 — проверяют диагонали через весь список ферзей — O(n) на проверку; множества `r + c`, `r − c` — O(1).
  * A3 — поиск в глубину вместо ширины находит путь, но не кратчайший.
  * A4* — чётность перестановки: каждый ход меняет её вместе с позицией пустой клетки, поэтому половина
    позиций недостижима (`21345_` — одна транспозиция).
  * B1 — ищут ход перебором всех `(кучка, остаток)` и проверкой XOR — верно, но медленно; правило: оставить
    `h ^ x`, если это меньше `h`.
  * B3 — путают, у кого обновлять alpha, а у кого beta; забывают передать окно в детей.
  * C1 — не останавливают партию после победы (тогда 9! = 362 880 последовательностей).
  * C2 — `range(1, n)` вместо `range(n + 1)`; позиция 0 — проигрышная.
  * C3 — XOR размеров кучек вместо XOR чисел Гранди (так работает только для обычного нима).
  * C4* — главная линия нужна для итеративного углубления: на следующей глубине первым смотрим её ход,
    и альфа-бета отсекает больше.
  * D2 — пересчитывают хэш с нуля после каждого хода — теряют смысл Зобриста.
  * D3 — сортируют детей по их первому листу, а не по значению поддерева.
  * E4а — сравнивают float и получают 4.999999; Fraction избавляет от этого.
  * E4в — классический результат: «держать на 20» даёт ≈ 8.14 очка за ход; с 21 ожидание точно такое же.
  * E5* — без кэша `(4, 4, 4)` не решится за урок; проверка победы только вокруг последней фишки ускоряет
    в разы (вместо всего поля — 4 направления).
